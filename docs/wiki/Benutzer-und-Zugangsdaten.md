# Benutzer und Zugangsdaten

CMS-Benutzer, gespeicherte Zugangsdaten und Erweiterungslizenzen haben unterschiedliche Aufgaben.

## CMS-Benutzer verwalten

Unter **Projekt → Benutzer** werden die Benutzer aus dem CMS geladen. **Neuen Benutzer anlegen** öffnet das Formular für Name, Benutzername, E-Mail, Rolle und Passwort. **Passwort zurücksetzen** öffnet das Formular für einen vorhandenen Benutzer. Das Passwort muss mindestens zwölf Zeichen lang sein.

Der Backend-Link öffnet die reguläre CMS-Anmeldeseite. Dort mit einem vorhandenen CMS-Benutzer anmelden.

## Zugangsdaten ablegen

Die Zugangsdatenfunktion speichert Bezeichnung, Benutzername, Passwort, URL und Notizen. Ein dort eingetragener Zugang erstellt keinen CMS-Benutzer und ändert kein CMS-Passwort. Bei der Benutzerverwaltung hinterlegt der Manager zugehörige Zugänge im Projekt.

Daten und Schlüssel im Manager-Datenordner gehören zusammen gesichert. Den Ordner nicht öffentlich bereitstellen oder in Git aufnehmen. Der Manager selbst hat keine Anmeldung; Zugriff auf den Manager ermöglicht auch Zugriff auf seine Verwaltungsfunktionen.

Lizenz-/API-Keys für Downloads werden unter [Erweiterungen und Lizenzen](Erweiterungen-und-Lizenzen.md) beschrieben.
