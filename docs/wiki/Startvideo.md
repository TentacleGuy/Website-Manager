# Startvideo

Beim Öffnen des Projektmanagers erscheint standardmäßig ein Startvideo mit Ton in einem Modal mit gerundeten Ecken. Der Hintergrund ist abgedunkelt. Das Video hat keine Wiedergabe-, Lautstärke- oder Spulsteuerung.

## Wiedergabe und Schließen

Das Video startet automatisch mit Ton, sofern der Browser dies erlaubt. Blockiert der Browser Autoplay mit Ton, wird es automatisch stumm abgespielt. Ein zusätzlicher Startknopf ist nicht erforderlich.

Das Fenster lässt sich jederzeit über das Kreuz oben rechts oder mit Escape schließen, auch während der Wiedergabe. Unter dem Video steht nur die Checkbox **Beim nächsten Start abspielen**.

## Beim nächsten Start abspielen

Unter dem Video ist **Beim nächsten Start abspielen** standardmäßig angehakt. Wird der Haken entfernt, erscheint das Video beim nächsten Öffnen nicht mehr. Die Auswahl wird im jeweiligen Browser gespeichert.

## Systemeinstellung

Unter **System → Startvideo** lässt sich **Startvideo beim Öffnen des Projektmanagers abspielen** ein- oder ausschalten. Die Einstellung und die Checkbox im Modal gelten für dieselbe Auswahl.

**Startvideo ansehen** öffnet das Video jederzeit als Vorschau, auch wenn die automatische Wiedergabe beim Start ausgeschaltet ist. Eine Vorschau schaltet die automatische Wiedergabe nicht von selbst wieder ein.

Wenn der Browser das Speichern lokaler Einstellungen blockiert, gilt eine Änderung nur bis zum Neuladen; die Oberfläche zeigt dazu einen Hinweis.
